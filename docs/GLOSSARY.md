# 용어·기호·런 카탈로그

`docs/`의 모든 문서가 공유하는 약속을 한곳에 모은 참조표다. 처음 읽는 독자는 이 문서를 먼저 훑고, 이후에는 모르는 기호가 나올 때만 돌아오면 된다.

전체 명세는 [`PROJECT.md`](../PROJECT.md), 문서 목록은 [`docs/README.md`](./README.md)에 있다.

## 한 문단 배경

특허 문헌을 과학기술표준분류 **17개 대분류 / 188개 중분류**로 자동 분류하는 인코더 모델을 만드는 프로젝트다. 한 특허가 여러 중분류에 해당할 수 있어(고유 문서의 14.1%) 문제는 **다중 라벨(multi-label) 188-way 분류**이고, 188개 출력에 각각 sigmoid를 걸어 임계값을 넘는 것을 모두 예측한다. 대분류는 별도로 예측하지 않고 예측된 중분류에서 매핑으로 유도한다([ADR-0002](./adr/0002-flat-multilabel-hierarchy.md)).

## 1. 라벨·데이터 기호

| 기호 | 뜻 |
| --- | --- |
| `Lno` / `Ltext` | 대분류 코드(17개, 예 `EA`) / 그 이름(예 `기계`) |
| `Mno` / `Mtext` | 중분류 코드(188개, 예 `EA01`) / 그 이름. **모델의 예측 타깃** |
| `documentId` | 특허 1건의 식별자(예 `kr20020059117b1`). 원천 데이터와 정답 라벨을 잇는 조인 키 |
| `k` | 한 문서에 붙은 정답 `Mno`의 개수(카디널리티). 1~8이며 평균 1.204, `k=1`이 문서의 85.0% |
| 다중-핫(multi-hot) | 정답을 길이 188의 0/1 벡터로 표현한 것. `k`개의 자리가 1이다 |
| 구 데이터 / 정리 데이터 | 데이터 클리닝([ADR-0010](./adr/0010-data-cleaning.md)) **전** train 201,895 / val 11,162 / test 11,271, **후** train 201,616 / val 11,132 / test 11,244. 두 데이터에서 나온 수치는 직접 빼지 않는다 |
| 길이 bin (B0~B3) | 문서 토큰 길이 구간. **B0** ≤512 · **B1** 512–1024 · **B2** 1024–2048 · **B3** >2048. 비교 축을 고정하려고 KoBERT 토크나이저 기준(`kobert_len`)으로 자른다 |

## 2. 평가 지표

주 지표는 **다중 라벨 micro-F1**이다. 아래 표의 나머지는 보조·진단용이다.

| 지표 | 뜻 |
| --- | --- |
| micro-F1 | 모든 (문서, 라벨) 인스턴스를 한 통에 넣고 계산한 F1. 흔한 클래스에 가중치가 실린다. **주 지표** |
| macro-F1 | 클래스별 F1을 단순 평균. 희소 클래스가 동등한 무게를 갖는다 |
| sample-F1 | 문서별 F1을 평균. 문서 단위 체감 성능 |
| top-1 weighted-F1 | 확률 최상위 1개만 예측했다고 보고 계산한 weighted-F1. **공식 baseline(0.8249)이 쓴 지표**라 비교선 정합용으로만 병기한다 |
| `P@k` | 상위 `k`개 예측 안에 정답이 든 비율 |
| R-Precision | 문서의 정답 개수만큼 상위에서 뽑았을 때의 정확도. **임계값과 무관**해 순위 품질만 잰다 |
| LRAP | 정답 라벨들이 예측 순위에서 얼마나 위에 있는지. 임계값과 무관 |
| empty rate | 임계값을 넘는 라벨이 하나도 없어 예측이 빈 문서의 비율 |
| `pt` | percentage point. `+0.84pt`는 micro-F1 0.8500 → 0.8584를 뜻한다 |
| 판정선 | 개선으로 인정하는 최소 micro 델타 = **0.6pt**. 그 아래는 시드 1런씩으로 확정하지 않는다([ADR-0011](./adr/0011-resource-constrained-methodology.md)) |
| paired bootstrap | 같은 test 문서를 두 모델에 동시에 태워 문서 단위로 재표집해 델타의 신뢰구간을 내는 절차 |

## 3. 훈련·모델 기호

| 기호 | 뜻 |
| --- | --- |
| `τ`(tau) | sigmoid 확률을 양성으로 판정하는 임계값. 이 프로젝트는 전역 **0.5** 고정([ADR-0004](./adr/0004-threshold-policy.md)) |
| Focal Loss `γ`·`α` | 쉬운 예제의 손실을 눌러 어려운 예제에 집중시키는 손실. `γ=2`, `α=0.25` |
| `max_len` | 모델이 읽는 최대 토큰 수. 이를 넘는 뒷부분은 잘린다 |
| `eff_batch` | 옵티마이저가 1스텝에 반영하는 문서 수(유효 배치). **학습률은 이 값만 따른다** |
| `micro_batch` | GPU에 한 번에 올리는 문서 수. `grad_accum`으로 누적해 `eff_batch`를 맞춘다. 메모리 제약이 정하는 값 |
| `grad_accum` | 기울기 누적 횟수. `eff_batch = micro_batch × grad_accum` |
| FA2 (FlashAttention-2) | 긴 시퀀스의 attention 메모리·속도 병목을 줄이는 커널 |
| unpadding | 배치 안의 패딩 자리를 계산에서 빼는 최적화 |
| `group_by_length` | 비슷한 길이의 문서끼리 배치로 묶어 패딩 낭비를 줄이는 샘플링 |
| TAPT | Task-Adaptive Pretraining. 대상 도메인 코퍼스로 MLM 계속학습을 한 뒤 분류를 파인튜닝하는 기법 |
| KD (지식 증류) | 강한 모델(teacher)의 출력 분포를 약한 모델(student)이 따라 배우게 하는 기법 |
| MCLoss | 계층의 상위 노드 점수를 하위 노드의 최댓값으로 묶는 계층 손실(C-HMCNN 계열) |

## 4. 프로젝트에서 굳어진 표현

문서 곳곳에 반복되는 자체 용어다.

| 표현 | 뜻 |
| --- | --- |
| **기준 런(앵커)** | 모든 비교의 고정 기준으로 삼은 훈련 런. 현재는 `11_01`이다 |
| **앵커 top-1 weighted-F1** | 위와 무관한 **지표 이름**이다 — 공식 baseline과 맞대려고 병기하는 top-1 weighted-F1 축을 가리킨다 |
| **축 / 축 종결** | 성능을 올리려는 시도의 갈래 / 그 갈래를 더 파지 않기로 확정한 상태. 종결된 축은 새 근거 없이 재제안하지 않는다 |
| **헤드룸** | 어떤 기법이 이론상 회수할 수 있는 성능의 상한 |
| **게이트** | 비싼 GPU 실험을 태우기 전에, 저장된 로짓만으로 착수 여부를 판정하는 사전 검사 |
| **프로브** | 본 훈련이 아니라 특정 값 하나를 재려고 짧게 돌리는 런(예: LR range test 300스텝) |
| **풀런** | 12 epoch을 끝까지 도는 본 훈련 |
| **공기(共起, co-occurrence)** | 두 라벨이 같은 문서에 함께 붙는 정도. **`lift` = 실제 동시출현 확률 ÷ 두 라벨이 독립일 때의 기대 확률**이며 1.0이 우연 수준이다 |
| **확신 오답** | 양성인데 확률 <0.1, 음성인데 확률 >0.9인 예측. 손실의 대부분을 무는 소수 원소 |
| **작동점(operating point)** | 모델이 예측을 얼마나 많이/적게 내는지의 균형. 예측량이 다른 두 런은 이 점을 맞춰야 오류 구성을 비교할 수 있다 |
| **오라클 …** | 정답을 안다고 가정했을 때 도달하는 값. 실제로는 닿을 수 없는 **상한**을 재는 장치다(오라클-`k`, 오라클-`τ` 등) |
| **로짓 덤프** | 훈련된 모델의 출력 점수를 `.npy`로 저장해 두는 것. 이후 분석은 GPU 없이 이 파일만으로 한다 |
| **SSOT** | Single Source of Truth. 어떤 수치·결정의 원본이 되는 파일. 값이 갈리면 SSOT를 따른다 |

## 5. 런 카탈로그 — 코드명 대조표

문서 본문은 노트북 코드(`11_01` 등)로 런을 지칭한다. 대응하는 노트북은 `notebook_output/`에 있다.

| 코드 | 읽는 이름 | 설정 | 결과·용도 |
| --- | --- | --- | --- |
| KoBERT (`03_01`) | **baseline 재현 런** | `monologg/kobert` · 512 · batch 8 · lr 3e-5 · 구 데이터 | micro **0.8502** / top-1 weighted 0.8148. 모든 비교의 출발선 |
| exp2 (`05_01`) | **512 대조 런** | A.X-Encoder · 512 · eff8 · lr 3e-5 · 구 데이터 | micro **0.8601**. KoBERT와 같은 창으로 묶어 모델 성분만 분리 |
| exp1 (`04_02`) | **장문 런(8192)** | A.X-Encoder · 8192 · eff8 · lr 3e-5 · 구 데이터 | micro **0.8685**(정리 test 재계산 0.8683). 최고 실측 |
| `09_01` | 손실 대조 런 — ZLPR | 512 · eff128 · lr 4.8e-4 · 구 데이터 | micro 0.8493. 미채택 |
| `09_02` | 손실 대조 런 — ASL | 위와 같음 + γ+0 / γ−4 / m 0.05 | micro 0.8362. 미채택 |
| `09_03` | 손실 대조 런 — BCE | 위와 같음, focal에서 `γ`·`α` 제거 | micro 0.8538. focal의 `γ` 값을 재는 진단용 |
| **`11_01`** | **기준 런(512)** | 512 · eff128 · lr 4.8e-4 · 12 epoch · seed 42 · **정리 데이터** | 정리 test micro **0.8588**. 이후 모든 비교의 기준 |
| `11_04` | 시드 재현 런 | `11_01`에서 seed만 153 | 훈련 잡음 측정(시드 델타 −0.18pt) |
| `12_01`·`12_02` | 풀링 프로브 | 은닉 상태 덤프 + 고정 풀링 비교 | 표현·풀링 축 종결([ADR-0012](./adr/0012-representation-pooling-closure.md)) |
| `13_01`·`13_02` | 도메인 사전학습 런(TAPT) | 특허 코퍼스 MLM 5 epoch → 분류 파인튜닝 | 정리 test micro 0.8572. 축 종결([ADR-0013](./adr/0013-domain-pretraining-closure.md)) |
| `14_01` | 계층 손실 런(MCLoss) | `11_01` + 17개 `Lno` 그룹 손실 항 | 정리 test micro 0.8467. 축 종결([ADR-0014](./adr/0014-hierarchy-loss-closure.md)) |
| `15_01` | LR range 프로브 | 300 step, 512·8192 두 조건 | 학습률 안전 판정 |
| **`16_01`** | **배포 런(4096)** | `11_01`에서 `max_len`만 4096 | 산출물 모델([final-run.md](./experiments/final-run.md)) |

로컬 CPU 분석 노트북(`06_xx` 오류·임계값·토크나이저 분석, `10_xx` 캘리브레이션·장문 프로브·데이터 클리닝, `11_02` 오류 분석)은 훈련 런이 아니라 저장된 로짓을 읽는 사후 분석이다.
