# 결정 기록(ADR)

프로젝트의 **주요 결정**을 사안별로 남긴다. 각 문서가 "무엇을 왜 결정했고, 어떤 대안을 왜 접었으며, 결과가 무엇이었나"를 기록한다.

[PROJECT.md](../../PROJECT.md)가 **최종 상태**를 담는다면 ADR은 **그 상태에 도달한 경위**를 담는다. 프로토콜과 실측 수치는 [experiments/](../experiments/)에 있고, ADR은 결정의 근거로 인용만 한다(수치를 중복 보관하지 않는다).

기호·용어·런 코드는 [GLOSSARY.md](../GLOSSARY.md)를 참조한다.

## 한눈에 보는 흐름

- **0001~0003**이 판을 정했다 — 무엇과 비교할지(자체 재현 baseline), 문제를 어떤 형태로 풀지(flat 다중 라벨), 어떤 모델을 쓸지(장문 인코더).
- **0004~0006**은 추론 시점의 레버를 닫았다 — 임계값·앙상블·캘리브레이션.
- **0009·0012~0015**는 훈련 시점의 레버를 하나씩 닫았다 — 손실 함수·풀링·도메인 사전학습·계층 손실·지식 증류.
- **0016**이 왜 그 레버들이 모두 상한에서 막혔는지에 물리적 근거를 붙였다 — 남은 오류의 상당 부분이 라벨 잡음이라 훈련으로 닿을 수 없다.
- **0017**이 배포 모델의 형태를 확정했다.

## 규약

- **파일명**: `NNNN-slug.md`(4자리 번호 + 영문 kebab slug). 번호는 부여 후 바꾸지 않는다.
- **상태**: `수용`(적용 중) / `제안`(결정 전·실험 대기) / `대체됨`(→ 대체 ADR 번호) / `폐기`.
- **서술**: 3인칭·사실 중심으로 쓴다(`CLAUDE.md` 「문서 서술 규칙」). 수정 이력은 문서에 남기지 않고 최종 결정만 서술한다. 결정이 바뀌면 새 ADR을 발행하고 기존 문서의 상태를 `대체됨`으로 바꾼다(덮어쓰지 않는다).
- **구조**: 맥락 → 결정 → 근거 → 검토한 대안 → 결과·영향 → 참조.
