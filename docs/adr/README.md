# 결정 기록 (ADR) — 프로젝트 정리·회고

프로젝트의 **주요 결정**을 사안별로 남기는 곳. 각 문서는 "무엇을 왜 결정했고, 어떤 대안을 왜 접었으며, 결과가 무엇이었나"를 기록한다 — 포트폴리오·회고의 SSOT.

`PROJECT.md`가 **최종 상태의 SSOT**라면, ADR은 **그 상태에 도달한 경위**를 담는다. 프로토콜·실측 수치는 `docs/experiments/*`가 소유하며 ADR은 결정의 근거로 인용만 한다(수치 중복 보관 금지).

## 규약

- **파일명**: `NNNN-slug.md`(4자리 번호 + 영문 kebab slug). 번호는 부여 후 불변.
- **상태**: `수용`(적용 중) / `제안`(결정 전·실험 대기) / `대체됨`(→ 대체 ADR 번호) / `폐기`.
- **서술**: 3인칭·사실 중심(`CLAUDE.md` 「문서 서술 규칙」). 수정 이력은 문서에 남기지 않고 최종 결정만 서술한다. 결정이 바뀌면 새 ADR을 발행하고 기존 문서 상태를 `대체됨`으로 바꾼다(덮어쓰지 않는다).
- **구조**: 맥락 → 결정 → 근거 → 검토한 대안 → 결과·영향 → 참조.
