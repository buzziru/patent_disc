# ADR-0007 — 손실 함수: 카디널리티 회수 겨냥

- **상태**: 제안 (레시피 확정 후 실험, 판정은 A/B 실측으로)
- **참조**: `docs/experiments/loss-function.md`(계획·프로토콜 SSOT), `docs/experiments/no-train-analysis.md` A, `NEXT_SESSION.md` 2단계

## 맥락

무훈련 분석으로 짜낼 수 있는 개선은 모두 닫혔다(계층 확장 [ADR-0002]·임계값 [ADR-0004]·캘리브레이션 [ADR-0006]·앙상블 [ADR-0005]). 남은 미회수 헤드룸은 **다라벨 문서의 카디널리티** 하나이며, 회수 경로는 손실 함수다. 현행 `FocalLoss(alpha=0.25, gamma=2)`는 `alpha`가 손실 전체에 곱해지는 상수라 클래스 균형 역할을 못 해, 문서당 음성:양성 ≈156:1인데 비대칭 처리가 사실상 γ 하나뿐이다.

## 결정 (방향)

**카디널리티를 겨냥한 손실로 교체를 시도한다.** 후보 착수 순서 **ZLPR → ASL →(필요 시) DL2(dice)**. 손실 계열(BCE 재가중)은 유지하되 ZLPR은 표적 정합 때문에 예외로 A/B에 포함한다. 최종 채택은 실측 후 확정한다(이 ADR을 갱신).

## 근거

- **표적은 다라벨 문서의 과소예측이다.** k≥2 문서는 전체의 15%지만 양성 라벨 인스턴스의 29.4%를 차지한다. 오라클 카디널리티 적용 시 exp1 micro가 0.8685→0.8848(**+1.63pt**, 3모델 +1.44~1.63pt). 기제는 정답 라벨이 늘수록 2번째 이후 양성이 τ 아래로 눌리는 과소예측(k≥2 평균 예측 1.93 vs 정답 2.355, 과소예측 44.3%). k=1은 오히려 과대예측이라 전역 캘리브레이션 문제가 아니다.
- 이 헤드룸은 임계값으로 닿지 않는다(global τ 오라클 헤드룸 +0.0000~+0.0008) — 손실이 점수 분포를 재배치해야 회수된다.
- **후보 순위**(두 축 — 카디널리티 정합·τ=0.5 강건성): ZLPR은 zero-bound로 문서별 가변 라벨 수를 직접 학습해 두 축 모두 최상. ASL은 γ+/γ− 분리로 눌린 양성 recall을 직접 회수하나 τ=0.5 정합 진단 필요. DL2는 F1 대리지만 배치 내 클래스별 양성 희소(배치 128에 ~0.8)로 불안정.

## 검토한 대안

- **손실 계열 변경(softmax·정규화 reduction)** — 미채택. Menon et al.(NeurIPS 2019) 기준 BCE 계열이 precision-일관이고, 대규모 다중레이블 시스템이 모두 BCE를 쓴다.
- **DL2(dice)** — 3순위. 변형(macro vs pooled)을 못박기 전엔 매력(F1 대리)과 위험(배치 불안정)이 같은 축에 있다.

## 결과·영향 (예정)

- 판정 기준은 **오라클-k 회수율**(k≥2 슬라이스 micro 개선을 상한 +1.63pt 대비)이며, 각 런에서 평균 예측 라벨 수·과소예측 비율·empty rate·val 최적 τ를 진단 병기한다. 전체 micro만 보면 k=1(문서 85%)에 희석된다.
- ⚠️ **선행 의존**: 레시피(배치·LR) 확정이 먼저다 — 배치·LR이 바뀌면 손실 최적 설정도 움직인다.
- ⚠️ **운영 이득은 판정 밖 해석이다.** 평탄화 벤치마크가 이 손실 계열의 불균형 이득을 과소평가한다는 논거는 도메인 기반 가설이며, 선택 근거로 쓰지 않는다(측정된 카디널리티 회수율로만 가른다). 상세 `docs/experiments/loss-function.md` 「운영 관점」.
