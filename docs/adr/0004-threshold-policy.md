# ADR-0004 — 임계값 정책: global τ 적용

- **상태**: 수용
- **참조**: `docs/experiments/no-train-analysis.md` B, `PROJECT.md` 「닫힌 갈래」

## 맥락

다중 라벨 예측은 sigmoid 확률을 임계값 τ로 자른다. 기본값 τ=0.5가 최적이 아니라는 신호가 있었다 — empty rate가 모델 간 비단조(1.16→1.79→1.35%)였고, threshold-free 랭킹 지표(LRAP·R-Precision)가 τ=0.5 F1보다 일관되게 우위였다. τ를 성능 레버로 쓸 수 있는지 물어야 했다. 후보는 (1) global τ(전역 단일 임계), (2) per-class τ_c(클래스별 임계).

## 결정

**global τ를 적용한다.** per-class τ는 배격한다. 튜닝은 **val에서 하고 test에 1회 적용**하며, 3모델에 동일 정책을 건다. τ=0.5 수치는 프로토콜 기준점으로 병기한다.

## 근거 (실측)

- **global τ는 레버가 아니다.** 오라클(test에서 직접 튜닝한 도달 불가 상한)로 재도 헤드룸이 micro +0.0000~+0.0008 / macro +0.03~0.19pt뿐이다. 최적점이 0.46~0.49로 0.5 바로 옆이고 val 곡선도 τ=0.35~0.55가 평평하다. **이득을 취해서가 아니라 손해를 피하려는 선택**이며 τ=0.5 유지와 사실상 동등하다.
- **per-class τ는 헤드룸이 크지만 도달 불가.** 오라클 헤드룸이 macro +1.52~1.62pt로 크나, val에서 벌고 test에서 전부 반납한다(일반화 격차 −0.0073~−0.0092). 채택 게이트(held-out 검증)는 작동하나(빼면 격차가 두 배) 그것으로도 못 막는다.
- **원인은 헤드룸 부재가 아니라 추정 한계다.** 학습 곡선에서 클래스당 양성 표본 ~18→~36→~71로 배가될 때마다 test 결손이 대략 절반씩 준다(3모델 공통). 손익분기는 클래스당 양성 **~140**(현 val의 2배)로 추정되며, 헤드룸의 상당 부분 회수는 그보다 훨씬 많은 표본을 요구한다.
- `train` 로짓 우회(클래스당 ~1,290개)는 성립하지 않는다 — 모델이 train을 학습해 확률이 과신되어 τ가 test로 전이되지 않는다.

## 검토한 대안

- **per-class τ_c** — 기각. 헤드룸은 있으나 현재 val 표본(클래스당 ~71)으로 도달 불가. 회복하려면 val 설계 단계에서 클래스당 양성 규모를 확보해야 한다.
- **문서 상대 임계(`p ≥ α·p_max`)** — 기각. sample-F1을 +0.66~0.85pt 올리나 **주 지표 micro를 −0.23~−0.52pt로 떨어뜨린다.**

## 결과·영향

- 유일한 의미 있는 이득은 exp1의 τ_macro=0.39로, test에서 sample-F1 +0.36pt·empty rate 1.35%→0.95%(일반화 격차 +0.0010). 이는 "다라벨 문서의 결손이 recall 쪽(FP:FN 0.33)"과 정합한다 — τ 하향이 recall을 올린다.
- 임계값 정책 갈래는 **닫혔다.** 다라벨 문서의 카디널리티 헤드룸은 임계값으로 닿지 않아 손실 함수로 넘겼다([ADR-0007](./0007-loss-function.md)).
