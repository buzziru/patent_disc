# ADR-0005 — 단일 모델: 앙상블 배격

- **상태**: 수용
- **참조**: `PROJECT.md` 「닫힌 갈래」·「Hard boundary」

## 맥락

훈련된 3모델(KoBERT 재현 / A.X@512 / A.X@8192)의 로짓을 평균하면 성능이 오르는지 측정할 수 있었다. 앙상블은 다중 레이블 시스템에서 표준적인 마지막 한 스푼이다.

## 결정

**앙상블을 채택하지 않는다.** 산출물은 운영 가능한 단일 모델이다.

## 근거

- **이득은 실재하나 작고, 비용이 불균형하다.** 3모델 로짓평균이 앵커 weighted-F1을 0.8256 → 0.8327(+0.71pt), 멀티라벨 micro를 0.8685 → 0.8752(+0.67pt)로 올린다. 그러나 **추론 비용이 3배**다.
- **운영 제약이 단일 모델을 요구한다.** 이 프로젝트의 산출물 정의(운영 가능한 단일 모델)와 정면으로 어긋난다 — +0.7pt를 위해 추론 비용 3배는 운영 관점에서 성립하지 않는다.

## 검토한 대안

- **3모델 로짓평균** — 이득 측정만 하고 불채택.
- **부분 앙상블(2모델)** — 검토하지 않음. 단일 모델 제약이 정도의 문제가 아니라 종류의 문제라, 2배도 같은 이유로 배격된다.

## 결과·영향

- 앙상블 갈래는 **닫혔다** — 새 근거 없이 재검토하지 않는다(`CLAUDE.md` Hard boundary에 명시).
- 개선은 단일 모델 내부에서 찾는다 — 레시피(배치·LR)·손실 함수([ADR-0007](./0007-loss-function.md))가 남은 경로다.
- 측정된 +0.71pt는 "단일 모델로 어디까지가 상한인가"의 참고선으로만 남긴다.
